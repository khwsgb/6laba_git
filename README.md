Лабораторная работа №6: Знакомство с Git и GitHub

Привет! Это репозиторий для выполнения лабораторной работы по системе контроля версий Git и платформе GitHub.

## 📋 Содержание проекта

1. Создание аккаунта на платформе GitHub
2. Настройка профиля и интерфейса пользователя
3. Работа с Codespaces — облачная среда разработки
4. Создание репозитория с лицензией MIT
   - Настройка публичного доступа
   - Добавление файла README
5. Загрузка файлов различных форматов (jpeg, png, txt, word, html, php, mp3)
6. Работа с ветвями
   - Создание трёх ветвей от основной
   - Внесение изменений в отдельную ветку
   - Слияние с основной веткой через Pull Request
7. Изучение Marketplace и подписка на разработчиков

|---------|-----------|---------------------|
